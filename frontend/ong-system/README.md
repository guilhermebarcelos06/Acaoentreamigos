<h1 align="center">🎗️ Sistema de Gestão para ONG</h1>

<p align="center">
  <strong>Um painel administrativo moderno e funcional para gestão de Organizações Não Governamentais.</strong>
</p>

<p align="center">
  Este projeto é uma aplicação web desenvolvida para facilitar o controle e a gestão de doações, voluntários e finanças de uma ONG. Desenvolvido com foco na usabilidade e performance.
</p>

<h2>✨ Funcionalidades</h2>
<ul>
  <li><strong>📊 Painel Geral (Overview):</strong> Visualização rápida de métricas importantes, gráficos e resumos de atividades.</li>
  <li><strong>💖 Gestão de Doações:</strong> Registro e acompanhamento de doações recebidas.</li>
  <li><strong>💰 Controle Financeiro:</strong> Gestão de receitas e despesas da organização.</li>
  <li><strong>🤝 Gestão de Voluntários:</strong> Cadastro e acompanhamento de voluntários ativos.</li>
  <li><strong>⚙️ Configurações:</strong> Personalização e ajustes do sistema.</li>
</ul>

<hr />

<h2>🛠️ Tecnologias</h2>
<p>As seguintes ferramentas e frameworks foram utilizados na construção do projeto:</p>
<ul>
  <li><strong>React:</strong> Biblioteca JavaScript para construção de interfaces.</li>
  <li><strong>TypeScript:</strong> Superconjunto JavaScript que adiciona tipagem estática.</li>
  <li><strong>Vite:</strong> Build tool rápida e leve para desenvolvimento moderno.</li>
  <li><strong>Tailwind CSS:</strong> Framework CSS utilitário para estilização rápida.</li>
  <li><strong>shadcn/ui:</strong> Componentes de interface acessíveis e personalizáveis.</li>
</ul>

<h2>🚀 Instalação e Execução</h2>

<h3>Pré-requisitos</h3>
<p>Certifique-se de ter o <a href="https://nodejs.org/">Node.js</a> e o gerenciador de pacotes <a href="https://pnpm.io/">pnpm</a> instalados.</p>

<h3>Passo a Passo</h3>
<ol>
  <li><strong>Clone o repositório:</strong>
    <pre><code>git clone [url-do-repositorio]</code></pre>
  </li>
  <li><strong>Acesse o diretório:</strong>
    <pre><code>cd ong-system</code></pre>
  </li>
  <li><strong>Instale as dependências:</strong>
    <pre><code>pnpm install</code></pre>
  </li>
  <li><strong>Execute em modo de desenvolvimento:</strong>
    <pre><code>pnpm dev</code></pre>
  </li>
</ol>
